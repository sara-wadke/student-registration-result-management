# Student Registration & Result Management

A simple web app to register students and manage their exam results, built with HTML, CSS and JavaScript.

## Features
- Student registration form with validation
- Add marks for five subjects and get total, percentage, grade and pass/fail
- Search, edit and delete results

## How to run
Open `index.html` in any browser. No installation needed.

## Note
Data is saved in your browser only (localStorage).
